**Лабораторная работа 3. Язык программирования с управляемой памятью. Умные указатели.**



Тема курсового проекта: игра "Сапер"



Три выбранных класса:

Cell — клетка игрового поля (состояние, наличие мины, числовая метка)

Field — игровое поле (сетка клеток, размещение мин, вычисление числовых меток)

Game — партия (управление игровым процессом, проверка победы/поражения)

Все три класса связаны в одну цепочку: Game использует Field, а Field состоит из Cell. Изолированных классов нет.
