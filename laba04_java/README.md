\##Сборка 



\### C++ (папка `laba04\_cpp`)

Для сборки потребуется компилятор с поддержкой C++17 (например, `g++` / MinGW).



```bash

\# Переход в папку

cd laba04\_cpp



\# Компиляция проекта

g++ -std=c++17 -Wall -Wextra \*.cpp -o main



\# Запуск

./main\_cpp

```



\### Java (папка `laba04\_java`)

Для сборки потребуется компилятор с поддержкой C++17 (например, `g++` / MinGW).



```bash

\# Переход в папку

cd laba04\_java



\# Компиляция проекта

javac \*.java



\# Запуск

java Main

```
